# Governance records

This directory will contain versioned, public-safe governance records created under the [Doctrine](../DOCTRINE.md) and [Operational Playbook](../PLAYBOOK.md).

No reviewer council, namespace authority, school partnership, institutional authorization, or publication program is activated by this directory.

Private contributor contact, eligibility, payment, dispute, or identity-verification records must never be committed here. Public records must identify exact scope, candidate bytes, reviewer competence, limitations, decision, date, and review due without exposing unnecessary private data.

## Founder decisions

- [KC-DEC-0001: First reference Knowledge Pack](decisions/KC-DEC-0001-first-reference-pack.md) — approves the English, D0/Green, Learn-lane scope for **AI Literacy Foundations for Nurses** and holds any Tagalog edition until the English source is stable and reviewed. It does not approve Pack bytes, schemas, review acceptance, publication, or institutional use.
